02 — Selected work

Things I built, and what they cost me.

Four of them. Each one has a decision in it I can defend, and at least one thing I would do differently.

JUN – AUG 2025Visa · internship

Security automation across a service fleet

PythonDockerCI/CDShell

The assignment was container security. The real problem was that fixing a vulnerability depended on somebody noticing it — so I automated Docker image remediation across 50+ microservices and moved the scans into CI/CD, where a regression fails the build instead of waiting on review. Then I wrote the runbook, so the automation outlived the internship.

2024Personal · full stack

Commerce platform, end to end

ReactSpring BootPostgreSQLDockerAWS EC2

Catalog, cart, checkout and an admin surface. React on the front, Spring Boot services behind it, PostgreSQL with real constraints rather than validation bolted onto the app layer, containerised onto EC2. I built it because I was already paying a platform to run a storefront and wanted to know what happened under the button.

OCT 2024 – APR 2025Centific

Inside the training data

AnnotationQAGuidelinesLLM data

Six months labelling and quality-checking the data models learn from — looking directly at the thing most people treat as a black box. Model behaviour is downstream of annotation guidelines, and an ambiguous guideline produces an ambiguous model. Every argument about AI output is really an argument about labels somebody wrote.

2026Coursework · vision

Camera calibration by direct linear transform

PythonNumPyOpenCV

Solved the projection matrix from point correspondences, then measured reprojection error back against the original image plane — because a calibration you have not reprojected is a calibration you are taking on faith.

03 — The company

Vaquxy

Born from pressure

Vintage streetwear, handcrafted — pieces cut, washed and finished by hand rather than pulled off a catalogue, so no two carry their wear the same way. I co-founded it and run the build side.

I own sourcing, pricing, inventory and every dollar of paid acquisition. Creative written, shot and cut in house, then tested daily against a CPA floor.

I read a funnel the way I read a stack trace — find where it drops, instrument it, fix it, re-measure. It is the same job as the engineering, with money as the test suite.
